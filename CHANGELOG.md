# CHANGELOG.md (Histórico de Mudanças)
Esse arquivo é utilizado para registrar o histórico de mudanças e evoluções ocorridas no projeto. O padrão mais aceito
mundialmente é o _Keep_ a _Changelog_. A ideia é agrupar as mudanças por tipos (Adicionado, Corrigido, etc.).

## Por que usar esse arquivo?
* **Transparência:** O _CHANGELOG_ evita que usuários fiquem "perdidos" sobre o que mudou em uma atualização.

Abaixo um exemplo de como pode ser estruturado esse arquivo:

```markdown
# Changelog
Todos os logs de mudanças notáveis neste projeto serão documentados neste arquivo.

## - 2024-05-20
### Adicionado
- Novo sistema de busca na documentação.
- Suporte para modo escuro (Dark Mode).

### Modificado
- Otimização do tempo de carregamento das imagens em 20%.

### Corrigido
- Erro de digitação no menu lateral da página inicial.

---

## - 2024-01-15
### Adicionado
- Versão inicial do projeto com as funcionalidades básicas.
- Estrutura de pastas e documentação técnica.

<!-- DICA: [Unreleased] pode ser usado no topo para mudanças que ainda não foram publicadas em uma versão oficial -->
```
